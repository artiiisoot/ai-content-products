01

국내 AI보안·IT보안·교육 컨퍼런스 자동 수집

01-conference-collector

국내에서 열리는 AI보안, IT보안, 교육 관련 컨퍼런스·전시·세션 일정을 자동으로 수집하고 Google Sheets에 정리하는 서비스입니다.

수집 · Apps Script기획 완료 / 구현 대기
주기
매주 월·수·금 09:00
수집 방식
UrlFetchApp으로 공개 페이지 조회
저장소
Google Sheets (5개 탭)
특징
중복 병합 · 변경 감지 · 캘린더 뷰

목적

  • AI보안·IT보안·교육(에듀테크, 메타버스/XR 교육 등) 관련 행사 정보를 주기적으로 수집
  • 일정·장소·주최/주관·참가 방식·등록 링크·주요 내용 기준으로 정리
  • Sheets에 누적해 검색·필터링·검토·캘린더 확인 가능
  • 여러 사이트를 직접 방문하지 않아도 신규·변경 행사를 빠르게 확인

핵심 기능 요약

  • 행사 정보 자동 수집
    • 행사명 · 기간 · 시간 · 장소 · 주최/주관 · 행사 유형(컨퍼런스/전시/세미나/웨비나/워크숍) · 참가비 · 사전등록 링크 · 원문 URL
  • 키워드 기반 카테고리 분류
    • AI보안 · IT보안 · 정보보안 · 사이버보안 · 에듀테크 · 온라인 교육 · AI 교육 · 메타버스/XR
  • 행사 내용 요약
    • 개요, 주요 세션·전시 주제, 참가 대상, 확인 포인트, 업무 관련도
  • 중복 행사 병합 — 공식 사이트·전시장 일정·협회 공지에 중복 등재된 행사를 행사명/날짜/장소/URL 기준으로 하나로 관리
  • 일정 변경 감지 — 행사명·날짜·장소·참가비·등록 링크·세션 변경 시 변경 전/후 값을 별도 컬럼 또는 이력 탭에 기록
  • 게시 — 자동 수집분은 게시 상태로 기록, 담당자가 카테고리·중요도·메모 직접 수정 가능
  • 캘린더 화면 — 시작일·종료일 기준 월별 표시, 카테고리별 색상 구분

시스템 구성

  • Apps Script 수집 스크립트 — 시간 기반 트리거, 주 3회(월·수·금) 09:00, UrlFetchApp으로 공개 페이지 조회·추출
  • 수집 대상 관리 탭
    • 사용여부 | 카테고리 | 사이트명 | URL | 수집방식 | 비고
    • 수집방식: 목록형 · 상세형 · 캘린더형 · 수동확인
  • 행사 데이터 탭
    • 수집일시 | 게시상태 | 카테고리 | 행사명 | 행사유형 | 시작일 | 종료일 | 시간 | 장소 | 주최/주관 | 참가비 | 등록링크 | 원문URL | 요약 | 변경여부 | 중요도 | 담당자메모
  • 변경 이력 탭
    • 변경감지일시 | 행사명 | 변경항목 | 이전값 | 변경값 | 원문URL
  • 캘린더 탭 — 월별 일정 표시, 카테고리별 색상, 예정/이번 주/종료 구분
  • 로그 탭

02

문서 브랜드명 표기·오타 자동 검수

02-figma-brand-guard

AI 오피스에서 전달받은 Figma·PPT 문서를 클로드가 검수해, 오타와 브랜드명 표기 오류를 찾아 수정안과 위치를 전달 매체에 맞는 형식으로 반환하는 서비스입니다.

검수 · ClaudeSPEC 초안
트리거
AI 오피스가 파일/링크 전달 시
입력
Figma 링크 · PPT 파일
기준 데이터
브랜드 용어집 (Sheets)
출력
매체별 위치 + 수정안

목적

  • Figma·PPT를 눈으로 검수하지 않아도 오타·브랜드 표기 오류를 자동 탐지
  • 브랜드 용어집(정식 표기 vs 오표기 후보) 대조로 일관된 브랜드명 보장
  • 수정 위치를 원본에서 바로 찾을 수 있는 형태(Figma 노드, PPT 슬라이드/도형)로 표시
  • 원본 매체에 맞는 포맷으로 반환해 바로 반영 가능

처리 흐름

  • ① AI 오피스가 검수 대상 파일 또는 링크(Figma 링크 / PPT 파일)를 전달
  • ② 문서에서 텍스트와 위치 정보를 추출
  • ③ 클로드가 오타 검수와 브랜드명 표기 검수를 수행
  • ④ 항목별 수정안과 원본 내 위치를 정리해 전달받은 매체 형식에 맞게 반환

핵심 기능 요약

  • 입력 수신 — Figma는 파일 키 기준 텍스트 노드 조회, PPT는 슬라이드별 텍스트 상자 조회
  • 오타 검수 — 맞춤법·띄어쓰기·중복 단어 등 일반 오탈자 후보 탐지
  • 브랜드명 표기 검수 — 용어집 대조 + 용어집에 없는 신규 오표기 패턴도 문맥상 후보로 제안
  • 수정안 생성 — 원문, 수정안, 검수 구분(오타/브랜드명), 판단 근거 기록
  • 위치 표기 — Figma: 노드 ID·프레임/레이어명 / PPT: 슬라이드 번호·도형 위치
  • 결과 반환 — Figma는 노드 기준 제안 목록, PPT는 슬라이드별 전/후 대조 리포트

데이터 구조

  • 브랜드 용어집 탭 (담당자 관리)
    • 정식표기 | 오표기 후보 | 구분(브랜드명/제품명) | 비고
  • 검수 결과 탭
    • 처리일시 | 원본매체 | 원본링크또는파일명 | 위치 | 원문 | 수정안 | 구분(오타/브랜드명) | 반영여부
  • 로그 탭
    • 실행일시 | 처리건수 | 지적건수 | 오류수 | 오류내용

시스템 구성

  • 입력 어댑터
    • Figma — Figma API/MCP로 파일의 텍스트 노드와 위치 조회
    • PPT — 슬라이드별 텍스트 상자와 위치 조회
  • 검수 엔진 — 추출된 텍스트와 브랜드 용어집을 함께 클로드에 전달해 오타·브랜드명 표기 검수 요청
  • 출력 어댑터
    • Figma용 — 노드 위치 기준 수정 제안 목록 (JSON 또는 코멘트 형식)
    • PPT용 — 슬라이드별 수정 전/후 대조 리포트
03

키워드 기반 뉴스·보도자료 자동 수집

03-news-collector

등록된 키워드를 기준으로 기업 뉴스룸과 네이버(포털) 보도자료를 자동으로 수집하고, Google Sheets에 정리해 주간 콘텐츠 후보 선정까지 이어지는 서비스입니다.

수집 · Apps ScriptSPEC 초안
주기
매일 1회 08:00
수집 우선순위
기업 뉴스룸 → 네이버 보완
중복 처리
URL 기준 1건만 유지
2차 산출
주간 콘텐츠 후보

목적

  • 등록 키워드별 관련 뉴스·보도자료를 주기적으로 자동 수집
  • 기업 뉴스룸을 우선 수집, 없거나 결과가 없으면 네이버 뉴스/보도자료 검색으로 보완
  • Sheets에 누적해 검색·필터링·검토 가능
  • 수집 기사 기반으로 주간 콘텐츠 후보(제목, 관련 키워드, 라온시큐어 연결 포인트) 선정
  • 여러 사이트를 직접 방문하지 않아도 키워드별 최신 보도 현황 파악

핵심 기능 요약

  • 키워드 기반 자동 크롤링 — 키워드 관리 탭을 순회, 뉴스룸 등록 키워드는 뉴스룸 우선, 신규 게시물 없으면 네이버 검색으로 대체
  • 기사 정보 추출 — 제목 · 언론사(뉴스룸 발행 주체) · 발행일 · 원문 링크 · 검색된 키워드
  • 요약 생성 — 본문 또는 스니펫 기반 짧은 요약, 요약 생성 시각 별도 기록
  • 중복 기사 제거 — 뉴스룸·네이버 중복 수집분은 URL 기준 1건만 유지

  • 사용자는 업체별 입력 파일(로고, 텍스트 정보)만 폴더에 넣고, 템플릿 반영·다운로드 설정은 자동 처리

사용 템플릿

  • Canva 디자인 — canva.com/design/DAHSPWh2P6c/…/edit
  • 레이아웃·폰트·색상 등 디자인 요소는 고정이며, 아래 4개 변경요소만 교체

변경요소 (템플릿 내 교체 대상)

  • 업체로고 — 상대 업체 로고 이미지
    • 템플릿의 로고 자리에 이미지로 교체
  • 업체명 — {업체명} + 라온시큐어㈜
    • ‘라온시큐어㈜’는 고정 문자열, 업체명만 입력값으로 채움
  • 장소명 — 체결식 장소, 텍스트 교체
  • 타이틀 — 행사/MOU 타이틀 문구, 텍스트 교체

입력 데이터 구조 (파일·폴더 인식 규칙)

  • 업체 1건 = 폴더 1개 — 폴더명과 폴더 내부 파일을 인식해 변경요소를 채움
    • input/{업체명}/logo.(png|jpg|svg) — 업체로고 원본 1개
    • input/{업체명}/info.txt (또는 info.json) — 업체명 · 장소명 · 타이틀
  • info.txt 예시
    • 업체명: (주)예시테크
    • 장소명: 라온시큐어 본사 대회의실
    • 타이틀: (주)예시테크 - 라온시큐어㈜ 업무협약(MOU) 체결식
  • 폴더명은 식별용이며 실제 반영 텍스트는 info.txt 값을 우선 (불일치 시 info.txt 기준)
  • logo 파일이 없거나 필수 항목(업체명/장소명/타이틀)이 비면 해당 폴더는 처리하지 않고 누락 항목을 알림

처리 흐름

  • 1. 입력 인식 — input/{업체명}/ 폴더를 스캔해 로고 파일 1개 + info.txt 텍스트 3항목을 읽음
  • 2. 템플릿 반영 — 지정 Canva 디자인을 열어 4개 변경요소(로고 이미지, 업체명+라온시큐어㈜, 장소명, 타이틀)를 교체
  • 3. 다운로드 추출 — 아래 설정으로 내보내기 실행
    • 파일 형식 — PDF (인쇄용)
    • 색상 프로필 — CMYK
    • 재단선 및 여백 — 포함
    • 페이지 — 모든 페이지 병합(단일 PDF 파일)
  • 4. 저장 — 결과 PDF를 output/{업체명}_MOU현수막.pdf로 저장

출력

  • 결과물 — 업체별 인쇄용 PDF 1개 (output/{업체명}_MOU현수막.pdf)
  • 처리 로그 — 어떤 입력값(로고 파일명, 업체명/장소명/타이틀 텍스트)이 반영됐는지 결과물과 함께 남겨 검수 가능
이 SPEC에는 「시스템 구성」 절이 없어, 같은 위치의 「출력」까지 수록했습니다.
