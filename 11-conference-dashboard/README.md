# 컨퍼런스 조회

라온이 참가·검토하는 컨퍼런스를 조회하는 화면입니다. 구글시트를 그대로 데이터로 씁니다.

```
브라우저(React) ──구글 로그인──▶ Sheets API ──▶ 컨퍼런스 운영 원장 · 2026_라온참가
```

## 구성

| 폴더 | 내용 |
|---|---|
| `web/` | React 화면 (Vite). 시트를 직접 읽습니다 |
| `src/` | Apps Script — 기존 시트에서 원장으로 탭을 복사하는 용도 (`copyLegacyTabs`) |

## 최초 1회 설정 — OAuth 클라이언트 ID

1. [Google Cloud Console](https://console.cloud.google.com/) 에서 **새 프로젝트** 생성
2. **API 및 서비스 → 라이브러리** 에서 `Google Sheets API` 검색 후 **사용 설정**
3. **API 및 서비스 → OAuth 동의 화면**
   - User Type: **외부** → 만들기
   - 앱 이름·지원 이메일 입력 후 저장
   - **대상(테스트 사용자)** 에 시트를 볼 사람의 구글 계정을 모두 추가
4. **API 및 서비스 → 사용자 인증 정보 → 사용자 인증 정보 만들기 → OAuth 클라이언트 ID**
   - 애플리케이션 유형: **웹 애플리케이션**
   - **승인된 JavaScript 출처**: `http://localhost:5173`
   - 만들기 → **클라이언트 ID 복사**
5. `web/.env` 파일을 만들고 붙여넣기

```
VITE_GOOGLE_CLIENT_ID=복사한값.apps.googleusercontent.com
```

## 실행

```bash
cd web
npm install     # 최초 1회
npm run dev     # http://localhost:5173
```

로그인 버튼을 누르면 구글 계정으로 인증하고 시트를 읽어옵니다.
권한은 **시트 읽기 전용**(`spreadsheets.readonly`) 하나만 요청하며, 토큰은 저장하지 않고 메모리에만 둡니다.
시트를 볼 수 있는 계정만 데이터를 볼 수 있습니다.
