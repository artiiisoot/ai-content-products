# 뉴스 수집 러너 — Windows 설치 패키지

담당자 Mac이 아닌 **다른 Windows PC**에서 일일요약/주간콘텐츠후보를 비상용으로 돌리기 위한 패키지입니다.
평소엔 필요 없습니다 — 담당자 Mac이 매일/매주 자동으로 처리합니다.

## 설치

1. 이 `windows` 폴더 전체를 새 Windows PC로 복사합니다 (USB, 사내 공유폴더 등 무엇이든 상관없습니다).
2. `1_setup.bat`을 더블클릭합니다.
   - Node.js가 없으면 `winget`으로 **자동 설치**를 시도합니다 (Windows 10/11에 기본 내장된 winget 사용, 최신 LTS 자동 설치).
     - 설치가 끝나면 창을 닫고 `1_setup.bat`을 다시 더블클릭해야 합니다 (새 PATH는 새 창부터 적용됨).
     - winget이 없는 예전 PC라면 [nodejs.org](https://nodejs.org)에서 LTS 버전을 수동 설치하라는 안내가 뜹니다.
   - `.env` 파일이 없으면 대화형으로 만들어줍니다 — 담당자에게 받은 `WEBAPP_URL`, `WEBAPP_TOKEN`, `LITELLM_KEY` 값을 입력하면 됩니다.
   - 네트워크 없이 도는 자가 점검(`selfcheck`)을 실행해 스크립트 자체가 정상인지 확인합니다.

## 실행

**반드시 사내망(VPN)에 연결한 상태**에서 실행하세요. 연결 안 돼 있으면 게이트웨이에 닿지 않아 실패합니다.

| 파일 | 하는 일 |
|---|---|
| `2_run-weekly.bat` | 주간콘텐츠후보 생성 (최근 7일 일일요약 기반, 없으면 최근 7일 수집 기사로 대체) |
| `3_run-daily.bat` | 일일요약 생성 (오늘 수집된 기사 기준) |

더블클릭하면 실행되고, 끝나면 결과 메시지가 창에 남습니다. 결과는 이 PC가 아니라 **구글시트에 바로 기록**됩니다.

> `.bat` 파일 안의 안내 문구는 일부러 영어로 되어 있습니다. Windows 콘솔(cmd.exe)의 기본 코드페이지가 한글 UTF-8을 깨뜨려서 명령어 파싱까지 오류가 나는 경우가 있어, 어떤 Windows 환경에서도 안전하게 동작하도록 한글을 빼고 만들었습니다. 대신 각 `.bat`은 시작할 때 `chcp 65001`로 콘솔을 UTF-8로 전환해두므로, `summarize.mjs`가 실행 중 출력하는 한글 메시지(예: "일일요약 기록 완료: 3건")는 창에 정상적으로 표시됩니다.

## 주의사항

- **`2_run-weekly.bat`은 중복 제거 로직이 없습니다.** 담당자 Mac의 자동 폴링(`check`)이나 시트의 "지금 생성 요청" 버튼과 겹쳐서 실행되면 주간콘텐츠후보가 중복으로 쌓입니다. 이 배치파일을 실행하는 동안엔 시트 버튼을 누르지 말고, 한 번만 실행하세요.
- **`LITELLM_KEY`는 담당자 Mac과 예산을 공유하는 키입니다.** 예산이 소진돼 있으면 `429 budget_exceeded` 오류가 나며, 재시도로는 해결되지 않습니다 — 담당자에게 예산 확인을 요청하세요.
- `.env`는 비밀값이 들어있으니 다른 사람과 공유하거나 커밋하지 마세요 (`.gitignore`에 이미 제외되어 있습니다).
- 이 폴더의 `summarize.mjs`는 상위 `runner/summarize.mjs`의 사본입니다. 상위 파일이 업데이트되면 이 사본도 다시 복사해서 최신화해야 합니다.
