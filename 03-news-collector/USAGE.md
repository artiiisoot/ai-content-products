# 뉴스 수집 자동화 — 사용 안내 (팀원용)

이 시스템은 **매일 아침 라온시큐어 관련 뉴스를 자동으로 모아서 구글 시트에 정리**해 줍니다.
여러분은 **인터넷 브라우저(크롬 등)로 구글 시트만 열면** 됩니다. 프로그램 설치나 명령어 입력은 필요 없어요.

> 📄 **뉴스 시트 열기**: [뉴스&보도자료 수집 시트](https://docs.google.com/spreadsheets/d/1HUhtF80Ox1kZ4GWhC7AeUzMBIA0s-WxZflu4k9QjXDY/edit)
> (Windows·Mac 상관없이 크롬/엣지/사파리 어디서든 동일합니다.)

---

## 내가 할 수 있는 일

| 하고 싶은 것 | 어디서 | 무엇을 하면 되나 |
|---|---|---|
| 뉴스 결과 보기 | 시트 열기 | `일일요약`·`주간콘텐츠후보` 탭 확인 |
| 새 키워드 추가/끄기 | 시트 `키워드 관리(…)` 탭 | 행 추가하고 `사용여부`에 `Y` 적기 (아래 설명) |
| 그 외 (스케줄 변경 등) | — | 담당자에게 요청 |

---

## 1. 새 키워드 추가하기 (가장 자주 쓰는 기능)

수집하고 싶은 검색어를 추가하는 방법입니다. 기술·경쟁사·컨퍼런스 키워드는 탭이 따로 있습니다.

1. 위의 **뉴스 시트 열기** 링크로 시트를 엽니다.
2. 아래쪽 탭 중 **`키워드 관리(기술)`**(일반 기술 키워드), **`키워드 관리(경쟁사)`**(경쟁사 동향), **`키워드 관리(컨퍼런스)`**(컨퍼런스·행사) 중 해당하는 탭을 클릭합니다.
3. 빈 줄에 다음을 채웁니다: **`사용여부`엔 `Y`**, **`키워드`엔 검색어**(예: `패스키`, `제로트러스트`). 나머지 칸(기업뉴스룸 URL·카테고리·등록일·비고)은 비워둬도 됩니다.
4. 끝. 저장 버튼 없어도 자동 저장됩니다.

> 💡 다음 날 자동 수집 때 이 키워드가 반영됩니다(기술 7시 / 경쟁사 8시 / 컨퍼런스 9시, 트랙마다 시간이 다릅니다). 즉시 확인하고 싶으면 담당자에게 "지금 수집 한 번 돌려달라"고 요청하세요.

**키워드를 잠시 끄고 싶다면**: 그 줄의 **`사용여부`** 칸을 `Y` → 비우기(또는 `N`)로 바꾸면 그 키워드는 수집에서 빠집니다. (행을 지울 필요 없이 꺼두기만 하면 됩니다.)

## 2. 결과 보기

| 탭 이름 | 내용 | 언제 갱신되나 |
|---|---|---|
| `뉴스 수집(기술)` / `뉴스 수집(경쟁사)` / `뉴스 수집(컨퍼런스)` | 그날 모인 기사 원본 (제목·언론사·요약·링크) | 매일 (기술 7시 / 경쟁사 8시 / 컨퍼런스 9시) |
| `일일요약` | 키워드별 그날의 핵심 동향 요약 (두 트랙 공통) | 매일 아침 (8시 30분경) |
| `주간콘텐츠후보` | 블로그로 쓸 만한 주제 5~7개 제안 | 매주 월요일 아침 (또는 담당자가 메뉴에서 수동 요청) |
| `로그` | 수집이 잘 돌았는지 트랙별로 기록 | 매일 |

## 자주 묻는 질문

**Q. 결과가 안 보여요 / 오늘 요약이 비어 있어요.**
그날 새로 수집된 기사가 없으면 요약도 생성되지 않습니다. `로그` 탭에서 `신규기사수`를 확인해 보세요. 그래도 이상하면 담당자에게 문의하세요.

**Q. 내가 시트를 잘못 건드리면 어쩌죠?**
`키워드 관리(…)` 탭의 `사용여부`·`키워드` 칸만 건드리면 안전합니다. 다른 탭(특히 `뉴스 수집(…)`·`일일요약`)은 시스템이 채우는 곳이니 직접 지우거나 고치지 마세요.

**Q. 나도 자동 수집을 내 PC에서 돌려야 하나요?**
아니요. 수집·요약은 **담당자 Mac 한 대가 자동으로** 처리합니다. 여러분은 시트만 보면 됩니다.

## (부록) 급할 때 요약/후보를 직접 돌리기 — Windows

평소엔 필요 없습니다. **담당자 Mac이 꺼져 있어 그날 요약이나 주간 후보가 안 나온 경우에만**, 사내망(VPN)에 연결된 Windows PC에서 아래처럼 직접 돌릴 수 있습니다. (개발 지식이 조금 필요하니 어려우면 담당자에게 요청하세요. 다른 PC에 처음 설치하는 경우엔 `runner/windows/` 폴더의 설치 패키지를 쓰세요 — 아래 별도 섹션 참고.)

1. [nodejs.org](https://nodejs.org) 에서 **LTS 버전** 설치
2. 담당자에게 받은 **러너 폴더**와 **`.env` 파일**을 한 폴더에 둡니다
   - `.env`에는 `WEBAPP_URL`, `WEBAPP_TOKEN`(공용), `LITELLM_KEY`(본인 키)가 들어갑니다
3. 그 폴더에서 **PowerShell**을 열고, 상황에 맞는 명령을 실행합니다:
   - 일일요약: `node --env-file=.env summarize.mjs daily` → `일일요약 기록 완료: N건`
   - 주간콘텐츠후보: `node --env-file=.env summarize.mjs weekly` → `주간 콘텐츠 후보 기록 완료: N건`
4. 성공 메시지가 나오면 시트에서 해당 탭(`일일요약` 또는 `주간콘텐츠후보`)을 확인하세요.

> ⚠️ **주의 (공통)**: 자동 실행은 담당자 Mac 한 대만 해야 합니다. 여러 사람이 동시에 돌리면 요약/후보가 중복으로 쌓입니다. 위 방법은 어디까지나 **비상용 1회 실행**으로만 쓰세요.
>
> ⚠️ **주간콘텐츠후보(weekly) 전용 주의**: `weekly`는 `daily`와 달리 **중복 제거 로직이 없어** 같은 시간대에 두 번 실행되면(예: 담당자 Mac의 자동 폴링과 겹치는 경우) 후보가 그대로 두 세트로 쌓입니다.
> - Windows에서 수동 실행하는 동안은 시트의 "지금 생성 요청" 버튼을 누르지 마세요 — 담당자 Mac이 2분 안에 그 요청을 감지해 자기도 `weekly`를 돌립니다.
> - 실행은 **정확히 한 번만**. 실행 후 `주간콘텐츠후보` 탭에 중복된 행이 없는지 확인하세요.
> - 이 러너는 담당자 Mac과 **같은 게이트웨이 키(예산)를 공유**합니다. 예산이 소진돼 있으면 `429 budget_exceeded` 오류가 나며, 이건 재시도로 해결되지 않고 담당자가 게이트웨이 예산을 올려줘야 합니다.

## (부록) 다른 Windows PC에 처음 설치하기

`runner/windows/` 폴더에 원클릭 설치 패키지가 있습니다. 사용법:

1. `runner/windows/` 폴더 전체를 새 Windows PC로 복사합니다 (USB, 사내 공유폴더 등).
2. `1_setup.bat`을 더블클릭 — Node.js가 없으면 winget으로 자동 설치를 시도하고(설치 후 창을 닫고 다시 실행 필요), `.env` 파일을 대화형으로 만들어줍니다.
3. 이후엔 `2_run-weekly.bat`(주간콘텐츠후보) 또는 `3_run-daily.bat`(일일요약)을 더블클릭만 하면 됩니다.

자세한 내용은 `runner/windows/README-Windows.md` 참고.
