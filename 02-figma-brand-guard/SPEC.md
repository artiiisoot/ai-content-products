# 문서 브랜드명 표기·오타 자동 검수 SPEC

AI 오피스(별도 보유 프로그램)에서 전달받은 Figma·PPT 문서를 클로드가 검수해, 오타와 브랜드명 표기 오류를 찾아 수정안과 위치를 전달 매체에 맞는 형식으로 반환하는 서비스입니다.

## 목적
- 담당자가 Figma·PPT 문서를 일일이 눈으로 검수하지 않아도 오타와 브랜드명 표기 오류를 자동으로 찾아냅니다.
- 브랜드 용어집을 기준으로 정식 표기와 오표기 후보를 대조해 일관된 브랜드명 사용을 보장합니다.
- 수정 위치를 원본 문서에서 바로 찾을 수 있는 형태(Figma 노드, PPT 슬라이드/도형)로 표시합니다.
- 결과를 원본 매체에 맞는 포맷으로 반환해, 담당자가 바로 반영할 수 있게 합니다.

## 처리 흐름
1. AI 오피스가 검수 대상 파일 또는 링크(Figma 링크 / PPT 파일)를 전달합니다.
2. 이 시스템이 문서에서 텍스트와 위치 정보를 추출합니다.
3. 클로드가 오타 검수와 브랜드명 표기 검수를 수행합니다.
4. 항목별 수정안과 원본 내 위치를 정리해, 전달받은 매체 형식에 맞게 반환합니다.

## 핵심 기능 요약
- 입력 수신
  - Figma 링크: 파일 키 기준으로 텍스트 노드를 조회합니다.
  - PPT 파일: 슬라이드별 텍스트 상자를 조회합니다.
- 오타 검수
  - 맞춤법, 띄어쓰기, 중복 단어 등 일반 오탈자 후보를 탐지합니다.
- 브랜드명 표기 검수
  - 브랜드 용어집(정식 표기 vs 오표기 후보)을 기준으로 문서 내 표기를 대조합니다.
  - 용어집에 없는 신규 오표기 패턴도 클로드가 문맥상 후보로 제안합니다.
- 수정안 생성
  - 원문, 수정안, 검수 구분(오타/브랜드명), 판단 근거를 함께 기록합니다.
- 위치 표기
  - Figma: 노드 ID, 프레임/레이어명
  - PPT: 슬라이드 번호, 도형/텍스트 상자 위치
- 결과 반환
  - Figma 입력 → 노드 위치 기준 수정 제안 목록
  - PPT 입력 → 슬라이드별 수정 전/후 대조 리포트

## 데이터 구조
- 브랜드 용어집 탭 (Google Sheets, 담당자 관리)
  - 컬럼: `정식표기 | 오표기 후보 | 구분(브랜드명/제품명) | 비고`
- 검수 결과 탭
  - 컬럼: `처리일시 | 원본매체 | 원본링크또는파일명 | 위치 | 원문 | 수정안 | 구분(오타/브랜드명) | 반영여부`
- 로그 탭
  - 컬럼: `실행일시 | 처리건수 | 지적건수 | 오류수 | 오류내용`

## 시스템 구성
- 입력 어댑터
  - Figma: Figma API/MCP로 파일의 텍스트 노드와 위치를 조회합니다.
  - PPT: 슬라이드별 텍스트 상자와 위치를 조회합니다.
- 검수 엔진
  - 클로드에게 추출된 텍스트와 브랜드 용어집을 함께 전달해 오타·브랜드명 표기 검수를 요청합니다.
- 출력 어댑터
  - Figma용: 노드 위치 기준 수정 제안 목록(JSON 또는 코멘트 형식)
  - PPT용: 슬라이드별 수정 전/후 대조 리포트

## 기술 스택 요약
- 검수 처리: 클로드
- Figma 연동: Figma API 또는 Figma MCP
- PPT 텍스트 추출: PPT 텍스트/도형 파싱 라이브러리
- 브랜드 용어집·검수 결과 저장: Google Sheets

## 인증/보안 전략
- Figma 접근은 담당자 개인 권한 범위 안에서만 수행합니다.
- 전달받은 PPT 파일은 검수 목적 외 외부로 전송하지 않습니다.
- 브랜드 용어집과 검수 결과 시트는 담당 인원만 접근할 수 있게 제한합니다.
- 검수 결과에는 원본 출처(링크/파일명)와 처리 일시만 남기고, 문서 원문 전체를 별도 저장하지 않습니다.

## 제외 범위
- AI 오피스 프로그램 자체 개발 — 이미 별도로 보유 중이며, 파일/링크 전달 인터페이스만 연동합니다.
- CI/BI 로고·색상 등 비주얼 자산 버전 관리 — 이번 SPEC은 텍스트(오타·브랜드명 표기) 검수만 다룹니다.
- Figma·PPT 외 문서 포맷(Word, PDF 등) — Phase 2에서 확장 검토합니다.

## Phase 1 개발 범위
- Figma 링크 텍스트 추출
- PPT 파일 텍스트 추출
- 브랜드 용어집 Google Sheets 탭 생성
- 클로드 기반 오타·브랜드명 표기 검수
- 검수 결과 탭에 위치 포함 기록
- 매체별(Figma/PPT) 결과 리포트 생성

## Phase 2 개발 범위
- Figma 코멘트 API로 직접 코멘트 등록
- PPT 파일에 수정 반영본 자동 생성
- Word, PDF 등 문서 포맷 확장
- 신규 오표기 패턴 발견 시 브랜드 용어집 업데이트 제안
- 검수 완료 시 Slack 또는 이메일 알림
