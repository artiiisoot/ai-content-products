# 블로그 콘텐츠 자동화 (AI 오피스 연동) SPEC

AI 오피스에서 만든 콘텐츠·이미지를 받아 Claude가 블로그 원고(Word)를 작성하고, 네이버 블로그에 비공개로 등록까지 자동화하는 서비스입니다. 로그인과 최종 공개 전환은 사람이 직접 수행합니다.

## 목적
- 담당자가 AI 오피스(별도 프로그램)에서 만든 콘텐츠 원본 + 이미지를 Claude에게 전달합니다.
- Claude가 이를 바탕으로 블로그 게시용 원고를 Word 파일로 작성합니다.
- Claude가 브라우저 자동화로 네이버 블로그 글쓰기 화면에 제목·본문·이미지를 채워 넣고 **비공개** 상태로 등록합니다.
- 담당자가 비공개 글을 최종 검수한 뒤, 직접 공개로 전환합니다.

## 처리 흐름
1. **콘텐츠 입력** — AI 오피스가 만든 텍스트 콘텐츠 + 이미지를 담당자가 Claude에게 전달합니다.
2. **원고 작성** — Claude가 전달받은 내용을 정리해 블로그 원고(Word, .docx)를 생성합니다. 제목, 본문, 이미지 삽입 위치를 포함합니다.
3. **네이버 블로그 접근** — Claude가 브라우저로 네이버 블로그 글쓰기 페이지에 접근합니다.
   - 로그인이 안 되어 있으면 담당자에게 직접 로그인을 요청합니다. **아이디·비밀번호는 Claude가 입력하지 않습니다.**
   - 로그인된 세션에서만 다음 단계로 진행합니다.
4. **비공개 등록** — 원고의 제목·본문·이미지를 네이버 블로그 에디터에 채워 넣고, 공개 범위를 **비공개**로 설정해 저장합니다.
5. **최종 검수 및 공개** — 담당자가 비공개 글을 확인하고 이상이 없으면 네이버 블로그에서 직접 공개로 전환합니다. (Claude는 공개 전환을 수행하지 않습니다.)

## 시스템 구성
- **입력**: AI 오피스 산출물 (텍스트 콘텐츠 + 이미지 파일), 담당자가 채팅으로 전달
- **원고 생성**: Claude + docx 스킬로 Word 파일 작성
- **블로그 자동화**: Claude in Chrome(브라우저 확장)로 네이버 블로그 글쓰기 페이지 조작
  - 로그인 상태 확인 → 미로그인 시 담당자에게 로그인 요청
  - 제목/본문/이미지 자동 입력
  - 공개 범위 "비공개" 지정 후 저장
- **검수/공개**: 담당자가 네이버 블로그에서 직접 확인 후 공개 전환 (수동)

## 기술 스택 요약
- 원고 생성: Claude (docx 스킬)
- 브라우저 자동화: Claude in Chrome MCP
- 이미지 첨부: AI 오피스 제공 이미지 파일을 블로그 에디터에 업로드

## 인증/보안 전략
- 네이버 로그인 아이디·비밀번호는 Claude가 절대 입력하지 않습니다. 로그인은 담당자가 브라우저에서 직접 수행합니다.
- Claude는 담당자가 로그인을 마친 세션에서만 이후 자동화를 진행합니다.
- 블로그 등록은 항상 "비공개" 상태로만 수행합니다. 공개 전환(되돌리기 어려운 게시 행위)은 담당자가 매번 직접 승인·수행합니다.
- 비공개 등록 직전, 등록될 제목·본문·이미지를 담당자에게 요약해 보여주고 진행 여부를 확인받습니다.
- AI 오피스 콘텐츠에 개인정보·민감정보가 포함되지 않았는지 원고 작성 단계에서 확인합니다.

## Phase 1 개발 범위
- AI 오피스 콘텐츠 + 이미지를 입력받아 Word 원고 생성
- 네이버 블로그 로그인 상태 확인 (미로그인 시 담당자에게 요청)
- 로그인 세션에서 제목·본문·이미지 자동 입력 → 비공개 저장
- 담당자 최종 검수 후 수동 공개 전환

## 제외 범위 (Phase 1)
- 로그인 자동화 (아이디·비밀번호 입력)
- 공개 전환 자동화
- 여러 편 배치 등록, 예약 발행
- 등록 이력 시트 관리
