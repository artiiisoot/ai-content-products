# 데일리 키워드 쿼리량 모니터링 SPEC

등록된 키워드의 네이버 검색 쿼리량(월간 PC/모바일 검색수)을 매일 자동으로 조회해 Google Sheets에 날짜별로 누적 기록하는 서비스입니다.

## 목적
- 담당자가 매번 네이버 검색광고 키워드도구를 수동 조회하지 않아도, 등록 키워드의 검색량 추이를 시트에서 바로 확인할 수 있게 합니다.
- `sample.jsx`(기존 통합 스크립트)의 네이버 수집 로직을 참고하되, GA4/Google Ads 등 다른 모듈은 포함하지 않고 키워드 쿼리량 기능만 새로 만듭니다.

## 대상 키워드
- 라온시큐어, 라온그룹, 라온, 라온메타, 라온메타데미, 옴니원, 옴니원NFT, 메타데미
- 담당자가 시트의 키워드 목록에서 추가·비활성화할 수 있습니다.

## 핵심 기능 요약
- 키워드 목록에서 사용여부가 켜진 키워드만 대상으로 합니다.
- 매일 오전 9시, 네이버 검색광고 API(키워드도구)로 각 키워드의 월간 PC/모바일 검색수를 조회합니다.
- 오늘 날짜로 이미 수집된 키워드는 다시 조회하지 않습니다(중복 방지).
- 결과를 날짜·키워드 단위로 시트에 누적 기록해 시계열로 조회할 수 있게 합니다.
- API 오류(요청 실패, 429, 키워드 미검색 등)는 해당 키워드만 스킵하고 나머지는 계속 진행하며, 오류 내용을 같은 행에 기록합니다.

## 데이터 정확성 주의사항 (sample.jsx 리뷰에서 확인된 함정)
- **월간 롤링값**: API가 주는 값은 "그날의 검색량"이 아니라 "최근 30일 누적치"입니다. 일별 순증가가 필요하면 전일값과의 차분을 별도 계산해야 합니다(Phase 2).
- **저빈도 키워드의 "< 10" 표기**: 검색량이 적은 키워드(라온메타데미, 옴니원NFT 등)는 숫자 대신 `"< 10"` 문자열로 옵니다. 이를 그냥 `10`으로 변환하면 안 되고, 원문 그대로 별도 컬럼에 남기거나 최소값(`<10`) 표시를 유지합니다.
- **키워드 매칭 실패 시 폴백 금지**: 응답 리스트에 요청 키워드와 정확히 일치하는 항목이 없을 때 임의로 다른 행(list[0])을 쓰지 않습니다. 매칭 실패는 오류로 기록하고 값은 비워둡니다.
- **신규/신조어 키워드 미색인**: 색인이 안 된 키워드는 결과 없음으로 오류 기록되는 것이 정상입니다(버그 아님).

## 시스템 구성
- Apps Script 수집 스크립트
  - 시간 기반 트리거로 매일 1회(오전 9시) 실행
  - 네이버 검색광고 API(`/keywordstool`)를 키워드별로 순차 호출 (HMAC-SHA256 서명 인증)
  - 429 응답은 지수 백오프로 재시도, 키워드 간 호출 간격을 둬 과호출을 방지
- 키워드 탭 (담당자 입력 가능)
  - 컬럼: `사용여부 | 키워드`
- 쿼리량 기록 탭
  - 컬럼: `수집일 | 키워드 | PC 검색량 | 모바일 검색량 | 합계 검색량 | 표시제한여부 | 오류내용 | 수집시각`
  - `표시제한여부`: 응답이 `"< 10"`처럼 정확한 값이 아닐 때 표시
  - `오류내용`: API 오류, 키워드 미매칭, 429 재시도 초과 등을 기록 (성공 시 빈칸)

## 기술 스택 요약
- 실행 환경: Google Apps Script
- 데이터 저장: Google Sheets
- 자동 실행: Apps Script 시간 기반 트리거 (매일 오전 9시)
- 외부 API: 네이버 검색광고 API 키워드도구 (`GET /keywordstool`)

## 인증/보안 전략
- 네이버 API 인증키(Customer ID, Access License, Secret Key)는 Apps Script 스크립트 속성에 저장합니다.
- 시트 공유 권한은 최소 인원으로 제한합니다.
- 개인정보를 수집하지 않습니다.
- 하루 1회만 정기 실행하고, 키워드 호출 사이 간격을 둬 API 과호출을 방지합니다.

## Phase 1 개발 범위
- 키워드 탭 생성 (담당자 입력 가능)
- 네이버 검색광고 API 연동 (인증, 검색량 조회)
- 매일 오전 9시 자동 수집 → 쿼리량 기록 탭에 날짜별 누적
- "< 10" 표시제한 값 보존, 매칭 실패 시 오류 기록 (임의 폴백 금지)
- 429 재시도, 오류 발생 시에도 나머지 키워드는 계속 진행

## Phase 2 개발 범위 (제외 범위 — 이번 스크립트에 포함하지 않음)
- GA4, Google Ads 등 다른 데이터 소스 연동 (별도 기획으로 분리)
- 전일 대비 순증가(차분) 계산
- 검색량 급증/급감 알림 (이메일/Slack)
- 월간 키워드(연관키워드 확장) 모니터링
