# 현수막 배경 인물사진 보정 자동화 SPEC

행사장에서 현수막을 배경으로 촬영한 인물사진을, 정해진 6가지 규칙에 따라 자동으로 보정·크롭·규격 변환하는 서비스입니다.

## 목적
- 사용자가 원본 사진을 Claude에게 전달하면, 아래 규칙을 순서대로 적용해 보정된 결과물(JPG) 1장을 반환합니다.
- 사람이 매번 포토샵으로 수동 보정하던 반복 작업(수평 맞추기, 반사 지우기, 톤 보정, 크롭, 규격 변환)을 자동화합니다.

## 처리 흐름 (핵심 검토 대상)

이미지 분석(좌표·영역 판단)과 실제 픽셀 처리를 분리합니다.

1. **분석 단계 (Claude Vision)** — 전달받은 사진에서 다음 좌표/영역을 JSON으로 판단합니다.
   - 현수막의 4개 꼭짓점 좌표 (휘어짐·기울기 보정 기준)
   - 인물 뒤 하얀 칠판(반사 발생 영역)의 사각형 범위
   - 인물 얼굴·피부 영역 (바운딩 박스)
2. **보정 단계 (이미지 처리 스크립트)** — 분석 결과를 입력받아 순서대로 픽셀 처리합니다.
   1. **원근/수평 보정** — 현수막 꼭짓점 4점으로 원근 변환(perspective transform)을 적용해 평면화 + 수평을 맞춥니다.
   2. **크롭** — 보정된 현수막이 상단을 꽉 채우는 비율로 프레임을 재설정합니다. (크롭을 먼저 확정해 이후 단계의 처리 범위를 줄입니다.)
   3. **반사 제거** — 화이트보드 영역 마스크에 inpainting을 적용해 반사된 인물/사물 흔적을 지웁니다.
   4. **색감/밝기 보정** — 화이트밸런스 자동 보정 + 노출/대비 정규화.
   5. **피부톤 보정** — 얼굴 바운딩 박스 내 피부 영역만 자연스러운 톤으로 보정 (과보정 방지를 위해 보정폭 상한을 둡니다).
   6. **출력 규격 변환** — 가로 800~900px로 리사이즈, DPI 200 이상으로 메타데이터 설정, JPG로 저장.
3. **검수** — 원본과 보정본을 나란히 미리보기로 제공합니다. 반사 제거·피부톤 보정처럼 오탐 가능성이 있는 단계는 결과를 사용자가 눈으로 확인 후 승인하는 것을 기본 전제로 합니다 (Phase 1은 완전 무인 자동화가 아님).

## 규칙별 상세

| 규칙 | 처리 방식 | 비고 |
|---|---|---|
| 현수막 휘어짐/수평 보정 | 4점 원근 변환 (perspective transform) | 꼭짓점 오검출 시 수동 좌표 지정 필요 |
| 칠판 반사 제거 | 반사 영역 마스킹 + inpainting | 반사가 진하거나 반투명하게 겹친 경우 완전 제거 보장 안 됨 |
| 색감/밝기 보정 | 자동 화이트밸런스 + 노출 정규화 | 원본이 극단적 저조도/역광이면 한계 있음 |
| 피부톤 보정 | 얼굴 검출 → 피부 영역 톤 보정 | 보정폭 상한으로 과보정(부자연스러움) 방지 |
| 상단 크롭 | 현수막 꼭짓점 기준 프레임 재설정 | 인물이 크롭 경계에 걸리지 않도록 여백 확보 |
| 출력 규격 | 가로 800~900px, DPI≥200, JPG | 세로는 원본 비율 유지 |

## 입력/출력
- **입력**: 사용자가 채팅으로 전달하는 원본 사진 (1장 단위 처리, Phase 1은 배치 처리 제외)
- **출력**: `원본파일명_corrected.jpg` — 위 6개 규칙이 모두 적용된 결과물 1장
- **처리 로그**: 어떤 보정이 적용됐는지(원근보정 각도, 크롭 좌표, 리사이즈 비율 등) 결과물과 함께 텍스트로 남겨 추후 검수 가능하게 합니다.

## 기술 스택 요약
- 좌표/영역 판단: Claude Vision (현수막 꼭짓점, 반사 영역, 얼굴 위치를 구조화된 JSON으로 응답)
- 픽셀 처리: Python (Pillow, OpenCV, NumPy) — 원근 변환, inpainting, 색보정, 리사이즈, DPI 메타데이터 설정
- 실행 방식: 사용자가 사진을 전달할 때마다 Claude가 분석 결과를 바탕으로 로컬 스크립트를 실행 (Phase 1은 수동 트리거, 배치/자동 워치 폴더는 Phase 2 검토)

## 인증/보안 전략
- 인물 사진은 개인정보(초상)를 포함하므로 원본·보정본 모두 로컬에서 처리하고 외부 업로드 없이 진행합니다.
- 결과물 저장 폴더의 접근 권한은 담당자로 제한합니다.

## 제외 범위 (Phase 1)
- 완전 무인 자동화 (반사 제거·피부톤 보정 결과의 사람 검수 없는 자동 확정)
- 여러 인물/여러 현수막이 한 장에 섞여 있는 경우의 개별 최적화
- 동영상/GIF 처리
- 배치(여러 장 동시) 처리
