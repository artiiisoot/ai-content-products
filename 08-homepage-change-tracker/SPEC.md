# 홈페이지 변경사항 트래킹 자동화 SPEC

자사·타사 홈페이지를 매일 자동으로 모니터링해 과거 데이터와 비교하고, 변경 여부에 따라 결과를 담당자에게 메일로 발송하는 서비스입니다. 자사 홈페이지는 오탈자·휴먼 에러 검수, 타사 홈페이지는 업데이트 동향 파악을 목적으로 합니다.

## 목적
- 담당자가 매일 수작업으로 홈페이지를 확인하지 않아도, 변경 여부를 자동으로 알 수 있게 합니다.
- 자사 홈페이지: 업데이트 시 오탈자·휴먼 에러를 놓치지 않도록 검수합니다.
- 타사 홈페이지: 경쟁사·관계사 홈페이지 업데이트를 추적해 동향을 파악합니다.

## 처리 흐름
1. **모니터링 요청** — 매일 지정 시각, AI오피스에 등록된 홈페이지 목록별 모니터링(크롤링)을 요청합니다.
2. **데이터 비교** — 크롤링 결과를 직전 저장된 과거 데이터와 비교합니다.
3. **변경 없음** — "이상없음" 메일을 발송합니다.
4. **변경 있음** — 변경된 위치를 표기한 PPT 보고서를 작성하고, 결과물을 첨부해 메일을 발송합니다.
   - 자사: 오탈자·휴먼 에러 여부를 함께 검수해 코멘트로 표기합니다.
   - 타사: 업데이트 내용을 트래킹해 동향 파악 코멘트를 표기합니다.

## 시스템 구성
- **홈페이지 목록 관리** (담당자가 시트에서 관리)
  - 구분(자사/타사), 홈페이지명, URL, 사용여부, 담당자, 비고
- **모니터링(크롤링)**: AI오피스에 홈페이지별 크롤링을 요청하고 결과를 전달받습니다.
- **과거 데이터 저장**: 홈페이지별 최근 수집 결과(콘텐츠 또는 스크린샷)를 스냅샷으로 보관합니다.
- **비교 로직**: 최신 수집 결과와 직전 스냅샷을 비교해 변경 여부·변경 위치를 판정합니다.
- **보고서 생성**: 변경 발생 시 변경 위치를 표기한 PPT를 생성합니다. (Claude + pptx 스킬)
- **메일 발송**: 비교 결과에 따라 "이상없음" 또는 "변경사항 발견 + 보고서 첨부" 메일을 발송합니다.

## 데이터 구조
- 홈페이지 목록 탭: `구분(자사/타사) | 홈페이지명 | URL | 사용여부 | 담당자 | 비고`
- 스냅샷 이력: `수집일시 | URL | 콘텐츠(또는 해시) | 스크린샷 경로`
- 비교 결과 로그: `비교일시 | URL | 구분(자사/타사) | 변경여부 | 변경위치 | 보고서파일 | 메일발송여부`

## 기술 스택 요약
- 모니터링(크롤링): AI오피스 연동
- 데이터 저장/비교: Google Sheets 또는 별도 저장소 (스냅샷 + diff)
- 보고서 생성: Claude (pptx 스킬)
- 메일 발송: Gmail 등 메일 발송 연동

## 인증/보안 전략
- 크롤링 대상은 공개 페이지로 한정하고, 로그인이 필요한 페이지는 제외합니다.
- 메일 수신자 목록은 담당자가 사전에 등록한 주소로만 제한합니다.
- 개인정보를 수집하지 않으며, 수집 데이터는 홈페이지 공개 콘텐츠로 한정합니다.

## Phase 1 개발 범위
- 홈페이지 목록 관리 탭 구성 (자사/타사 구분)
- AI오피스 연동으로 매일 자동 크롤링 요청
- 과거 스냅샷과 비교해 변경 여부 판정
- 변경 없음 → "이상없음" 메일 발송
- 변경 있음 → 변경 위치 표기 PPT 생성 → 첨부 메일 발송

## Phase 2 개발 범위
- 자사 홈페이지 오탈자·맞춤법 자동 검수 연동
- 타사 홈페이지 변경 이력 누적 및 동향 리포트 자동화
- 변경 이력 대시보드
- 변경 빈도·패턴 기반 알림 우선순위 조정

## 제외 범위 (Phase 1)
- 로그인 필요 페이지 크롤링
- 오탈자 자동 교정 (Phase 1은 검수 코멘트까지만)
- 변경 이력 대시보드
