# MOU 현수막 디자인 제작·추출 자동화 SPEC

Canva의 지정 템플릿(MOU 체결식 현수막)에 업체별 변경요소(로고·업체명·장소명·타이틀)를 자동 반영하고, 인쇄용 규격으로 다운로드까지 자동 처리하는 서비스입니다.

## 목적
- MOU 체결 때마다 반복되는 "현수막 템플릿에 업체 정보 채워 넣기 → 인쇄용 PDF로 내보내기" 수작업을 자동화합니다.
- 사용자는 업체별 입력 파일(로고, 텍스트 정보)만 폴더에 넣고, 나머지(템플릿 반영·다운로드 설정)는 자동으로 처리됩니다.

## 사용 템플릿
- Canva 디자인: `https://www.canva.com/design/DAHSPWh2P6c/53tSxIxJ6giq5sHkZPChng/edit`
- 이 템플릿의 레이아웃·폰트·색상 등 디자인 요소는 고정이며, 아래 4개 변경요소만 교체합니다.

## 변경요소 (템플릿 내 교체 대상)

| 변경요소 | 내용 | 비고 |
|---|---|---|
| 업체로고 | 상대 업체 로고 이미지 | 템플릿의 로고 자리에 이미지로 교체 |
| 업체명 | `{업체명} + 라온시큐어㈜` | "라온시큐어㈜"는 고정 문자열, 업체명만 입력값으로 채움 |
| 장소명 | 체결식 장소 | 텍스트 교체 |
| 타이틀 | 행사/MOU 타이틀 문구 | 텍스트 교체 |

## 입력 데이터 구조 (파일·폴더 인식 규칙)

업체 1건 = 폴더 1개. 폴더명과 폴더 내부 파일을 인식해 변경요소를 채웁니다.

```
input/
  {업체명}/
    logo.(png|jpg|svg)   # 업체로고 원본 (1개)
    info.txt (또는 info.json)  # 업체명, 장소명, 타이틀 텍스트
```

- `info.txt` 예시:
  ```
  업체명: (주)예시테크
  장소명: 라온시큐어 본사 대회의실
  타이틀: (주)예시테크 - 라온시큐어㈜ 업무협약(MOU) 체결식
  ```
- 폴더명은 업체 식별용이며, 실제 반영 텍스트는 `info.txt` 값을 우선합니다(불일치 시 `info.txt` 기준).
- `logo` 파일이 없거나 `info.txt`에 필수 항목(업체명/장소명/타이틀)이 비어 있으면 해당 폴더는 처리하지 않고 누락 항목을 알립니다.

## 처리 흐름

1. **입력 인식** — `input/{업체명}/` 폴더를 스캔해 로고 파일 1개 + `info.txt` 텍스트 3항목을 읽습니다.
2. **템플릿 반영** — 지정 Canva 디자인을 열어 4개 변경요소(로고 이미지, 업체명+라온시큐어㈜, 장소명, 타이틀)를 교체합니다.
3. **다운로드 추출** — 아래 설정으로 내보내기를 실행합니다.

   | 설정 항목 | 값 |
   |---|---|
   | 파일 형식 | PDF (인쇄용) |
   | 색상 프로필 | CMYK |
   | 재단선 및 여백 | 포함 |
   | 페이지 | 모든 페이지 병합(단일 PDF 파일) |

4. **저장** — 결과 PDF를 `output/{업체명}_MOU현수막.pdf`로 저장합니다.

## 출력
- **결과물**: 업체별 인쇄용 PDF 1개 (`output/{업체명}_MOU현수막.pdf`)
- **처리 로그**: 어떤 입력값(로고 파일명, 업체명/장소명/타이틀 텍스트)이 반영됐는지 결과물과 함께 남겨 검수 가능하게 합니다.

## 기술 스택 요약
- **우선 방식 — Canva Connect API (Autofill API)**: 대상 디자인을 브랜드 템플릿으로 등록하고, 로고/업체명/장소명/타이틀을 필드로 매핑해 API로 자동 채움 + PDF 내보내기. (Canva Teams/Enterprise 플랜 및 브랜드 템플릿 등록 필요)
- **대안 방식 — 브라우저 자동화**: Autofill API 사용이 불가한 플랜일 경우, 브라우저 자동화(Claude Browser 등)로 Canva 편집 화면에 직접 로그인해 요소 교체 → 다운로드 다이얼로그(PDF 인쇄용/CMYK/재단선/병합 옵션) 설정 → 다운로드를 수행합니다.
- 실행 방식: 업체 폴더가 `input/`에 준비될 때마다 수동 트리거로 실행 (Phase 1은 배치 워치 폴더 자동 감지 제외)

## 인증/보안 전략
- Canva 로그인 인증 정보(계정/토큰)는 로컬 환경변수로 관리하고 코드/저장소에 포함하지 않습니다.
- 업체 로고 등 상대방 자산은 해당 MOU 건 처리 목적으로만 사용하고, 처리 완료 후에도 `input/` 폴더에 원본 그대로 보관(별도 외부 업로드 없음)합니다.

## 제외 범위 (Phase 1)
- 템플릿 자체의 레이아웃/디자인 변경 (레이아웃 커스터마이징은 다루지 않음)
- 여러 템플릿(현수막 외 배너, 포스터 등)으로의 확장
- 업체 정보 자동 수집(회사명 검색, 로고 자동 크롤링 등) — 로고·텍스트는 사용자가 폴더에 직접 준비
- 배치(여러 업체 동시) 처리의 병렬 실행 최적화 — 순차 처리 기준
